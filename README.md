## Estructura del repositorio

Este repositorio sirve como ancla a los diversos "satélites" (proyectos), en los que me encuentro trabajando pero que se encuentran dispersos y hasta hace muy poco tiempo ocultos en mi disco duro local.

Toda la estructura este proyecto en particular se basa en directorios y archivos descriptivos.
Cada proyecto cuenta con su propio directorio y diversos archivos como evidencia y documentación de los resultados, adicionalmente cada proyecto cuenta con su archivo README con una breve descripción del proyecto, su estado actual y los hitos destacados durante su desarrollo.

También se integra un índice con el enlace directo a los repositorios enlistados en este proyecto para facilitar el acceso a cada uno de ellos.
